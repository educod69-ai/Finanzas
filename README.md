# Finanzas

Aplicación personal para llevar gastos, ingresos y ahorros mes a mes. Funciona en el navegador, sin servidor y sin conexión.

**URL:** https://educod69-ai.github.io/Finanzas/

## Añadir al iPhone

1. Abre el enlace en **Safari**.
2. Toca **Compartir**.
3. Elige **Añadir a pantalla de inicio**.

## Datos

Los datos se quedan solo en el dispositivo (localStorage del navegador). Exporta copias de seguridad con regularidad desde la propia aplicación.
